# reef-policy

The repository policy of **Reef**, version control built for a world where AI agents write most of the code ([ADR 0061](../../docs/adr/0061-repository-policy-file.md)). A policy is `reef-policy.toml` at the root of a tree: strict TOML tables that name the owners of the policy, groups of identities, the attestor sets whose evidence counts, the evidence a change needs for which paths, size limits, forbidden paths, sign-off areas and conflict tiers, each with an optional CEL condition, plus free CEL rules. The crate loads a file into a `Policy`, with a `Diagnostic` (rule, key, line, column) per problem, and evaluates it over one change's `Input` into an `Evaluation`: a decision (`allow`, `block`, `no_policy`, `invalid_policy`) and a result per rule, with the evidence still missing and the sign-offs still needed.

Modules: `format` (the file and its checks), `glob` (path patterns, ASCII case-insensitive), `env` (the CEL environment and Reef's functions `glob`, `any_glob`, `all_glob` and `matching`), `check` (Reef's static check of an expression), `cost` (the cost bound), `input` (what a policy sees), `eval` (attestor sets, the tables, the rules and the result), `conflict` (`Policy::conflict_tier`) and `schema` (the file, the input and the evaluation as JSON Schema). Format 1's limits: a 256 KiB file, 256 entries, 64 groups of 256 members, 64 attestor sets, 256 patterns a list; an expression of 8 KiB, 1,000 nodes and nesting 48; a cost of 10^7 an expression and 5×10^7 an evaluation.

CEL runs on cel-rust's `cel`, pinned exactly (`=0.15.0`, no default features but `regex`), and used from `env`, `check` and `cost` only, since each of its minor releases has broken its API. cel-rust has no type checker and no cost limit, so the static check and the cost bound are Reef's own; every load and evaluation runs on a thread with a 64 MiB stack, because cel-rust's parser recurses before its depth limit applies. An upgrade is its own change that runs the corpus in `tests/corpus/`.

It depends on no Reef crate but `reef-error`, and on no jj-lib, gRPC, SQLite or tokio, so the daemon, the `reef` binary (`reef policy check` works offline) and the phase-four store share it. [`docs/policy.md`](../../docs/policy.md) is the format for a policy's author. The design document and roadmap are at <https://github.com/reef-vcs/reef>.
