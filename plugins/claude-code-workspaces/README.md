# Reef workspaces

This plugin makes every worktree Claude Code creates (`claude --worktree`, the `EnterWorktree` tool, subagents with `isolation: worktree`) a Reef workspace instead: a copy-on-write copy of the repository on its own jj change, snapshotted as it is written, held while the session runs and reclaimed with a final snapshot after it ends. It calls `reef ws provider` (https://github.com/reef-vcs/reef/blob/main/docs/workspace-provider.md) from Claude Code's `WorktreeCreate` and `WorktreeRemove` hooks, and holds a resumed session's workspace again from its first prompt (`UserPromptSubmit`).

What changes:

- A workspace has no `.git`: `git status` in it fails, and Claude Code's check for uncommitted changes finds none, so it removes an unnamed session's worktree without asking. Nothing is lost: the release snapshots first.
- Work lands as a jj change (`reef log`), not a branch.
- `.worktreeinclude` is not applied; untracked files stay in your checkout.
- A workspace is held while a session that uses it runs, and reclaimed with a final snapshot when its lease runs out after that (35 minutes by default). Subagents' workspaces last until the session ends. A background session the supervisor stops loses its hold the same way; a name used again later starts on the change its last workspace left.
- The first worktree in a repository registers it with Reef, which initializes jj beside git there (`reef init` does the same, and says so).
- The repository is the one the session is in when it asks for the worktree, which follows `cd`.

Requires Claude Code 2.1.300 or later. A plugin's `WorktreeCreate` hook does not run for `claude --worktree --tmux`, which then makes a git worktree; to use Reef there too, put this plugin's `hooks/hooks.json` entries in a settings file (`~/.claude/settings.json`). Claude Code refuses a worktree inside a git repository, so if your home directory is one, set `REEF_STATE_DIR` to a directory outside it.

It runs the `reef` on your `PATH`; install Reef first (https://github.com/reef-vcs/reef#install). Then:

```sh
claude plugin install reef-workspaces --marketplace reef-vcs/reef
```
